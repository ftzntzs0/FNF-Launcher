# FNF V-Slice Mod Launcher

If you download a lot of FNF V-Slice mods, your base game folder probably gets messy real quick. Dumping everything into the native `mods` directory usually leads to overwritten files, clutter, or a broken base game. This launcher was built to fix exactly that.

## The Main Feature: True Mod Isolation

Instead of mixing all your mods together, this launcher lets you keep them in a completely separate folder anywhere on your PC. 

When you hit play, the launcher temporarily injects only that specific mod into the game directory. The second you close the game, it pulls the mod right back out. 

Your main FNF directory stays 100% clean and vanilla at all times. No leftovers, no accidental overwriting, and no broken files. It is completely risk-free modding.

## Key Features

* **Risk-Free Modding:** Keeps your base game folder completely untouched and free of clutter.
* **Instant Search:** Built-in search bar that filters your mod library in real-time as you type.
* **Smart Sorting:** Automatically tracks your history so your last played mods stay at the top of the pile.

## How to Set Up

1. Open the launcher and head over to the **Settings** tab.
2. Select the path to your main game executable (`FNF.exe`).
3. Select the folder where you actually keep and hoard your mods.
4. Go back to **Home**, pick a mod, and hit play.
